# 텍스트 곡과 `& MPLAY`

곡(tune)은 텍스트로 쓴 짧은 음악입니다. 같은 텍스트가 Apple II에서는 그대로 연주되고(Applesoft BASIC의 `& MPLAY "!..."`),
윈도우에서는 `.MBF` 파일로 컴파일됩니다(`src\tune\tune2mbf.bat`). 이 `.MBF`는 윈도우 플레이어와 Apple II 드라이버가 모두 재생할 수 있습니다.

```
src\tune\tune2mbf.bat -o twinkle.MBF "T120 O4 L4 CCGGAAG2 FFEEDDC2 / O3 L2 CGFC GCFC"
src\win_player\play_mbf.bat twinkle.MBF
```

## 표기법

곡은 `/`로 나눈 최대 6개의 성부(voice)로 이루어집니다. 1~3번 성부는 칩 1의 채널 A~C(왼쪽), 4~6번 성부는 칩 2의 채널 A~C(오른쪽)에서
연주됩니다. 그 이상의 성부는 무시합니다. 모든 성부는 `T120 L4 O4 V12`로 시작하므로, 한 성부에서 쓴 명령이 다른 성부에 영향을 주지 않습니다.
공백과 알 수 없는 문자는 무시하고, 대소문자는 구분하지 않습니다.

| 명령 | 뜻 |
| --- | --- |
| `C D E F G A B` | 음표. 뒤에 `#` 또는 `+`는 올림, `-`는 내림, 그 뒤에 길이, 그 뒤에 점 |
| `R` | 쉼표. 음표처럼 길이와 점을 붙입니다 |
| `L<n>` | 기본 길이: 1은 온음표, 2는 2분음표, 4는 4분음표, 8은 8분음표 … 최대 64 |
| `O<n>` | 옥타브 0~7. `O4 C`가 가운데 도(261.6 Hz)입니다 |
| `<` `>` | 한 옥타브 내림 / 올림 |
| `T<n>` | 템포(분당 4분음표 수), 32~255 |
| `V<n>` | 음량 0~15 |

음표 뒤의 길이(`C8`, `G2`)는 그 음표에 한해 기본 길이를 바꿉니다. 점 하나는 바로 앞 값의 절반을 더합니다(`C4.`는 4분음표 + 8분음표).
3틱(60 ms) 이상인 음표는 마지막 1틱이 무음이어서, 같은 음이 반복되어도 따로따로 들립니다.

시간은 50 Hz 틱 단위의 정수입니다. 온음표는 `12000 / T` 틱이고, 1/n 길이의 음표는 온음표 틱 수를 n으로 나눈 값(버림, 최소 1틱)입니다.

## Apple II의 `& MPLAY`

`src\mb_basic\`은 DOS 3.3용 3.2 KB 프로그램 `MPLAY`(로드 주소 `$7D00`)를 만듭니다. 이것은 `src\dist\mb.dsk`에 메뉴 `HELLO`,
프로그램 `DEMO`, `PLAYMBF`와 함께 들어 있습니다. 프로그램 안에서(또는 직접 입력해서) 이렇게 씁니다:

```
10 PRINT CHR$ (4);"BRUN MPLAY"
20 & MPLAY "!T120 O4 L8 CDEFGAB>C4"
30 & MPLAY "SONG"
40 & MPLAY "SONG",1
```

- `BRUN MPLAY`가 명령을 설치합니다(`$03F5`의 `&` 벡터를 설정하고 `HIMEM`을 `$6900`으로 낮춥니다). 프로그램이 문자열을 만들기 전, 그리고
  `BRUN TYPE` 뒤에, 처음에 한 번만 하세요.
- `& MPLAY "!곡"`은 곡을 컴파일해서 연주합니다. `& MPLAY "NAME"`은 디스크 카탈로그에 있는 `.MBF` 파일 NAME을 연주합니다.
  파일은 연주하는 동안 DOS의 RWTS로 곧바로 읽습니다(디스크에서 다시 채우는 4 KB 링 버퍼). 그래서 프롬프트에서 직접 입력해도 되고,
  곡은 디스크만큼 클 수 있으며, B 형식과 T 형식 파일 모두 됩니다. 인자는 `A$` 같은 어떤 문자열 식이어도 됩니다. 곡 텍스트는 최대 255자
  (Applesoft 문자열 한도)이고 컴파일된 곡은 최대 3,840바이트입니다. 더 긴 곡은 잘리고 소리가 멈춥니다.
- `& MPLAY "NAME",1`은 곡이 끝나면 다시 시작합니다(아무 키나 누르면 멈춥니다). `,2`는 ESC나 Q가 아닌 키를 누르면 곡을 멈추는 대신
  음악 위에 짧은 효과음을 냅니다(테스트에서 이것을 씁니다).
- 연주하는 동안 프로그램은 멈춰 있습니다. 곡이 끝나거나 키를 누를 때까지입니다(누른 키는 소비됩니다).
- 오류는 DOS의 것을 그대로 쓰므로 `ONERR GOTO`가 됩니다: `I/O ERROR`(디스크 오류, 또는 모킹보드 없음), `FILE NOT FOUND`,
  `FILE TYPE MISMATCH`(MBF1 곡이 아닌 파일). 그 밖의 `&` 단어는 벡터에 전에 있던 루틴으로 넘깁니다.
- 메모리: `$6900-$89FF`만 씁니다(`ADDON_MEMORY.md` 참고). 그래서 일반 DOS 3.3 디스크와 K-HANGEUL / KBASIC 디스크 모두에서 돌아갑니다.
  제로 페이지는 `$06-$09`, `$EB-$EF`, `$FA-$FE`를 씁니다.

6502 컴파일러(`mb_tune.s`)와 파이썬 컴파일러(`tune2mbf.py`)는 정수 연산을 쓰는 같은 알고리즘입니다. `src\mb_basic\test\run_basic_tests.bat`는
MAME에서 Apple II가 파이썬과 똑같은 바이트를 만드는지, 그리고 AY 레지스터 쓰기가 일치하는지 확인합니다.
